Pill-shaped CTA button in Votean's warm-teal system. Use `primary` for the one main action per screen, `dark` for a secondary strong action (e.g. "Teilen"), `outline`/`subtle` for lower-emphasis actions, `ghost` for inline text links.

```jsx
<Button variant="primary" icon="refresh" fullWidth>Weiter abstimmen</Button>
<Button variant="ghost">Alle ansehen</Button>
```

Variants: primary (teal fill + colored shadow), dark (ink-900 fill), outline (white + teal border), subtle (sand fill, muted text — used for already-resolved states like "Ergebnisse"), ghost (no background/padding, teal text, for inline links).
